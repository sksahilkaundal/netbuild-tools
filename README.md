# netbuild

Netbuild tools for Revit / BIM coordination -- by **SKAEC.COM** (https://skaec.com).
Free tools are MIT-licensed (root `LICENSE`); paid products carry their own proprietary licence agreement.

| Product | Where | Licence | What it does |
|---|---|---|---|
| **Level Shift by Netbuild** | [`LevelShifter/`](LevelShifter/README.md) | MIT | Move up to 10 levels; every element, group and model element hosted to them keeps its X, Y, Z. pyRevit ribbon buttons (Netbuild tab), a Windows app and a command line |
| **Plot Runner by Netbuild** | `ProjectA_PlotRunner/` (PR #5) | MIT | ProjectA Plot GA export pass, model by model, verified on disk |
| **Revit MCP Router by Netbuild** | `scripts/RevitMcpRouter/` (PR #3) | Proprietary | Lets Claude / any MCP client drive several Revit sessions, routed per chat session |
| **Remote Router by Netbuild** | `RevitMcpRemote/` (PR #2) | Proprietary | The Router's tools from Claude on the web, over an authenticated tunnel |
| **Revit Status by Netbuild** | `scripts/` (PR #3) | Proprietary | Revit / Autodesk session status, tray app |

Every product is named "*Tool* by Netbuild" and has an About screen with product info, version,
requirements and license -- see [`CLAUDE.md`](CLAUDE.md) for the conventions.
