# Netbuild logo set (charcoal frame, green nodes)

Each logo is its own file. Text is converted to outlines (Inter Medium / Regular, SIL OFL), so the SVGs look
the same on any computer and can go straight to a printer. `svg/` holds the masters; `png/` holds
transparent exports.

| Logo | SVG | PNG |
|---|---|---|
| Mark only | `netbuild-mark.svg` | `netbuild-mark-512/192/32.png` |
| Mark, reversed (dark backgrounds) | `netbuild-mark-reversed.svg` | `netbuild-mark-reversed-512/192/32.png` |
| App icon / favicon | `netbuild-icon.svg` | `netbuild-icon-512/192/32.png` |
| Primary lockup "Netbuild by SKAEC" | `netbuild-logo.svg` | `netbuild-logo.png` (240 px tall), `-80h.png` |
| Primary lockup, reversed | `netbuild-logo-reversed.svg` | `netbuild-logo-reversed.png`, `-80h.png` |
| LinkedIn square (no rounded corners; LinkedIn masks it) | `netbuild-linkedin-square.svg` | `netbuild-linkedin-400.png` |
| Level Shift by Netbuild | `level-shift-logo(-reversed).svg` | `level-shift-logo(-reversed)(-80h).png` |
| Plot Runner by Netbuild | `plot-runner-logo(-reversed).svg` | `plot-runner-logo(-reversed)(-80h).png` |
| Revit MCP Router by Netbuild | `revit-mcp-router-logo(-reversed).svg` | `revit-mcp-router-logo(-reversed)(-80h).png` |
| Remote Router by Netbuild | `remote-router-logo(-reversed).svg` | `remote-router-logo(-reversed)(-80h).png` |
| Revit Status by Netbuild | `revit-status-logo(-reversed).svg` | `revit-status-logo(-reversed)(-80h).png` |

Colours: ink `#1A1A1A`, node green `#0F6E56`, subtitle `#5F5E5A`. Reversed: white `#FFFFFF`, node mint
`#5DCAA5`, subtitle `#B4B2A9` (lighter than `#5F5E5A` so it stays readable on dark backgrounds).
PNG sizes: 512 for web, 192 for app icons, 32 for favicons. `-80h` lockups are for email signatures and
document headers.
`netbuild-logos.zip` holds all of the above.
