# Netbuild brand assets

The Netbuild mark is an **N drawn as a braced structural frame**: two columns, one diagonal brace and four
bolted nodes. It reads as *build* (frame) and *net* (nodes). Colours come from the Revit Tools design
tokens (`design/revittools_theme.py`): indigo `#5f60ff` (accent), ink `#212121`.
The wordmark is Archivo Expanded Bold (SIL Open Font Licence), converted to outlines, so the SVGs need
no font installed.

## Files

| File | Use |
|---|---|
| `netbuild-mark.svg` | App icon / favicon / avatar: indigo tile, white frame |
| `netbuild-mark-mono-dark.svg`, `netbuild-mark-mono-light.svg` | One-colour versions (stamps, title blocks, print) |
| `netbuild-logo.svg` | Horizontal logo on light backgrounds |
| `netbuild-logo-reversed.svg` | Horizontal logo on dark backgrounds |
| `netbuild-logo-stacked.svg` | Mark above wordmark (square-ish spaces) |

## Rules
- Keep clear space around the mark of at least one node diameter (about 1/6 of the tile).
- Do not recolour the frame, stretch the logo, or set the wordmark in another typeface.
- The product name stays "*Tool* by Netbuild" (see `CLAUDE.md`); the logo carries only "Netbuild".
