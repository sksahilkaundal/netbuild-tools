NB-01

Level Shiftby Netbuild

v1.4.0 · no key

Moves up to 10 levels up or down while every element, group and model element hosted to them keeps its X, Y, Z. Each offset from a moved level changes by the opposite amount, and every element is measured before and after.

  • New elevation or a move (+up / −down) per level, current elevation shown read-only
  • Check (plan only), Trial run (rolled back), then Apply as one Undo entry
  • Walls, floors, ceilings, roofs, columns, framing, stairs, railings, rooms, MEP, families, doors
  • Model group members compensated in place; ungrouped, fixed and regrouped only when needed
  • Bounding box of every model element compared; anything that moved is listed by Id

Ribbon button (inside Revit)

  • Windows 10 / 11, 64-bit
  • Autodesk Revit 2019–2026
  • pyRevit 4.8 or later, IronPython engine

App and command line

  • No Python needed for the .exe files
  • Revit open with pyRevit and the Revit MCP extension listener running

The model

  • A project model, opened editable; workshared levels not borrowed by others
NB-02

Plot Runnerby Netbuild

v1.3.0 · no key

Runs a GA sheet export pass model by model through your own export scripts, which it reads and never edits. Every PDF and DWG it reports is checked on disk.

  • One model at a time: it checks the model is open in Revit and binds to it by title
  • Revision date in any spelling; each model's own date format is read live before exporting
  • PDF only, DWG only, or both: all PDFs first, then all DWGs, per category
  • Every sheet with that revision date, or only the sheets you list (single, list or series)
  • Each file verified: written this pass, not empty, a real %PDF or AutoCAD header; DWG byproducts swept
  • A stalled batch drops to one sheet per call; every step logged with its file list

App and command line

  • Windows 10 / 11, 64-bit; no Python needed for the .exe files

Revit

  • Autodesk Revit 2022 or later (Revit's own PDF export)
  • pyRevit, IronPython engine, with the Revit MCP extension listener running
NB-03

Revit MCP Routerby Netbuild

v1.3.7 · per-PC licence

Lets Claude Code, or any MCP client, drive any of several open Revit sessions on one computer, chosen per chat session by document, Revit version or port. It follows a document across a Revit restart and refuses to guess when the choice is ambiguous, so a command never runs on the wrong model.

  • Revit 2023, 2024, 2025 and 2026 open side by side, each on its own port from 48884 up
  • Several models in one Revit: list open documents, run a task per model by title, dry run or apply
  • Setup app connects Claude Code in one click (and Codex when it is installed)
  • Shipped as native-compiled binaries with a signed, per-machine activation

This computer

  • Windows 10 / 11, 64-bit; no admin rights, no Python
  • Autodesk Revit 2023–2026 with pyRevit and the Revit MCP connector extension
  • Claude Code, or another stdio MCP client

Licence

  • One licence per computer (Machine ID)
  • Internet to activate and at bridge start; 7 days offline grace
NB-04

Remote Routerby Netbuild

v0.5.0 · uses the Router's licence

The Router's tools and session routing, served as a remote MCP server so Claude on the web, desktop and mobile can drive Revit on your PC through a custom connector. Nothing is opened on your network.

  • Binds 127.0.0.1 only; an outbound Cloudflare Tunnel is the one way in
  • OAuth 2.1 sign-in with your passphrase (PKCE, token refresh); 5 wrong attempts lock sign-in for 15 minutes
  • Quick tunnel, or a named tunnel on your own domain for a fixed URL
  • Up to 10 independent slots, each with its own connector URL and its own selected Revit
  • Privacy switches: no code over the connector, no logging, tools denied by name

This computer

  • Windows, with Revit open on the same PC
  • Revit MCP Router by Netbuild installed and licensed here
  • Python 3.10 or later with mcp and httpx

Reaching it from Claude

  • cloudflared; a Cloudflare account and domain for a named tunnel
  • A Claude plan that supports custom connectors
NB-05

Revit Statusby Netbuild

v1.2.4 · per-PC licence

A small window and system-tray icon that shows, live, every running Revit with the document it has open, and every Claude Code session on the machine with the Revit it is routed to.

  • Per Revit: version, process, open document and how long it has been active
  • Per Claude Code session: whether it has a live bridge to Revit, which port and document, and its uptime
  • Tray colour gives the overall state: green connected, amber no document or bridge, red listener down
  • Click a session row to bring that session to the front in the Claude app

This computer

  • Windows 10 / 11, 64-bit; no install, no admin rights, no Python
  • Autodesk Revit 2023–2026 with pyRevit and the Revit MCP connector
  • Claude Code desktop app for the sessions list
  • Optional: Revit MCP Router by Netbuild

How they work

Nothing is applied that hasn't been checked

Model changes are made the way a coordinator would want to make them by hand: plan first, rehearse, then commit as one step you can undo.

1 / Check

Plan only

Lists what would change and why, with element Ids. The model is not touched.

2 / Trial run

Rehearse and roll back

Runs the change for real inside a transaction, measures the result, then rolls it back.

3 / Apply

Commit as one Undo

Applies the change as a single named entry, so one Ctrl+Z in Revit reverses all of it.

Measured, not assumed

Level Shift compares every model element's bounding box before and after. Plot Runner opens each exported file and reads its header.

Refuses to guess

When two open models could match a request, the Router stops and asks. A command never lands on the wrong Revit.

Your files stay yours

Export scripts are read, never edited. The Remote Router serves from your own PC, behind your own passphrase.
